# Power BI Dashboard Guide

## 1. Dashboard Overview

The E-Commerce Sales & Delivery Analytics dashboard provides an interactive view of sales performance, customer orders, product categories and delivery operations using the Olist Brazilian E-Commerce dataset.

## 2. Key Performance Indicators (KPIs)

The dashboard displays the following KPI cards:

| KPI | Description |
|---|---|
| Total Orders | Total number of distinct orders |
| Total Product Revenue | Revenue generated from product prices |
| Average Order Value | Average product revenue per unique order |
| Average Delivery Days | Average calendar days between purchase and customer delivery |

## 3. Sales Analysis

### Monthly Revenue Trend
A line chart showing how product revenue changes over time, helping identify monthly sales patterns.

### Revenue by Product Category
A bar chart comparing product revenue across different categories to identify major revenue contributors.

## 4. Order Analysis

### Order Status Breakdown
A donut chart showing the distribution of orders by status, such as delivered, shipped, canceled and unavailable.

## 5. Delivery Performance

The dashboard includes delivery performance measures:

- Average Delivery Days
- Late Orders
- On-Time Orders
- Late Delivery Rate

Late orders are identified by comparing actual delivery dates with estimated delivery dates.

## 6. Interactive Filters

The dashboard includes the following slicers:

| Filter | Purpose |
|---|---|
| Purchase Date | Filters analysis by order purchase date |
| Product Category | Filters results by product category |
| Payment Method | Filters results by payment type |

These filters allow users to explore different segments of the e-commerce business.

## 7. Tools Used

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- MySQL
- Olist Brazilian E-Commerce Dataset

## 8. Business Applications

The dashboard can help businesses:

- Monitor sales performance.
- Identify high-revenue product categories.
- Understand order status distribution.
- Monitor delivery performance.
- Explore purchasing patterns across different periods and payment methods.
